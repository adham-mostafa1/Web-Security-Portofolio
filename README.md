# Web-Security-Portofolio

Welcome to my Web Security portfolio. This repository documents my practical journey in vulnerability research and penetration testing. It serves as a structured reference for the write-ups and proof-of-concepts (PoCs) I develop while exploring various security labs and applications.

## 🎯 Objectives
- Document my learning path in Web Application Security.
- Share practical exploitation techniques and methodologies.
- Build a structured knowledge base for common web vulnerabilities.

## 📁 Repository Structure
The repository is organized into folders, each representing a different lab or vulnerable application. Inside each folder, you will find detailed write-ups for the discovered vulnerabilities.

*(Note: Platforms and write-ups will be added progressively as I continue my research.)*
